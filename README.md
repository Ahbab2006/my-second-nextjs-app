# 🧪 My-second-nextjs-app / Test Project

A lightweight experimental playground built with Next.js to test features, component structures, API routes, and modern web workflows.

---

## 🎯 Purpose of This Project

This repository serves as a testing sandbox created to:
- Test Next.js (App Router) routing, layouts, and page structures.
- Experiment with UI components and styling with Tailwind CSS.
- Test server-client data flow and API handling.
- Verify configuration setups before implementing them in larger production apps.

---

## 🛠️ Built With

- **Framework:** Next.js
- **Language:** TypeScript / JavaScript
- **Styling:** Tailwind CSS
- **Runtime:** Node.js
